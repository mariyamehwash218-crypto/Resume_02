# Resume_02
A simple resume made using HTML5 and CSS3
Styled Resume Page

About the Project

This is my second web development assignment. I created a simple resume webpage using HTML and CSS.

Features

- Personal introduction
- Education details
- Skills section
- Projects section
- Interests section
- Simple and clean layout
- Responsive design for smaller screens

Technologies Used

- HTML5
- CSS3

Files

- "index.html" - Contains the structure and content of the resume.
- "style.css" - Contains the styling and layout of the resume.

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

What I Learned

- Creating a resume using HTML.
- Styling sections with CSS.
- Using margins and padding.
- Creating a responsive webpage.
- Organizing webpage content.
